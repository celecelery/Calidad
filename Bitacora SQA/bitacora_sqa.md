# Bitácora SQA

Registro de las actividades de aseguramiento de calidad del proyecto Dashboard de Monitoreo SQA (Ctrl+Zac).
Cada actividad de QA agrega una fila nueva al final de la tabla; las filas no se borran ni se reescriben.
Si una decisión cambia después, se agrega una fila nueva que haga referencia a la anterior.
